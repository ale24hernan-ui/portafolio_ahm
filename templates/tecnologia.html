Ingeniería de Software & Empatía Digital

Reducir la Fricción Tecnológica para Facilitarle la Vida a las Personas

Para quien creció entre código y pantallas, leer un correo, estructurar un archivo o usar un sistema es tan natural como respirar; pero comprendí que esa facilidad es un privilegio que no todos tuvieron. Aplico todo lo que aprendo en ingeniería de software y ciencia de datos para acortar la distancia entre el punto A y el punto B, haciendo que la tecnología trabaje a favor de las personas y no al revés.

Sistemas Creados para Ayudar a Personas Reales

Proyecto Gran Blanco (Asistente Operativo Híbrido APEX)

Iniciativa Personal de Automatización • Arquitectura ERP/CRM

Proyecto personal nacido al observar la brecha digital en el entorno laboral: donde antes una persona sufría con múltiples pasos técnicos para redactar un correo, consultar información o generar un documento, diseñé a APEX para reducir al mínimo los movimientos necesarios entre el punto A y el punto B, aliviando la carga operativa de mis compañeros y entregando certidumbre inmediata a mis líderes.

  • Puente Accesible por WhatsApp: Orquestación autohospedada en Docker y n8n conectada a WhatsApp Business Cloud API oficial, llevando funciones complejas a la aplicación que todos ya saben usar.
  • Inteligencia Invisible: Clasificador de red silencioso con IA que interpreta la intención del usuario en JSON puro y automatiza la generación de documentos con Gotenberg (100% open-source) y PostgreSQL.
Python n8n Docker PostgreSQL WhatsApp Cloud API ERP REST API Gotenberg

Art-Tours Transfer (SaaS Logístico B2B)

2026 | Plataforma de Gestión y Transporte

Plataforma web y sistema SaaS de reservas y logística de transporte turístico e interurbano, creado para simplificar el control de unidades en ruta y automatizar confirmaciones sin papeleo manual.

  • Arquitectura backend construida con Python y Flask servida mediante Gunicorn en Render.
  • Generación instantánea de comprobantes y disparo de eventos por webhooks hacia flujos automatizados en n8n.
  • Base de datos relacional en PostgreSQL e interfaz ágil en Vanilla JavaScript.
Python Flask PostgreSQL Gunicorn Render Vanilla JS

Brave Power Studio & Soluciones Digitales

2026 | Clientes Privados (Xalapa / Cancún)

Desarrollo de plataforma web y sistema de administración de reservas para estudio de entrenamiento en Xalapa, Veracruz, además de soluciones digitales para marcas independientes, ahorrando horas de gestión manual a sus fundadores.

  • Flujos de agendamiento intuitivos integrados con avisos automatizados por WhatsApp.
  • Diseño responsivo pensado para que cualquier usuario reserve en segundos desde su teléfono.

Evaluación de Ganancias y Riesgo Petrolero

Noviembre 2026 | TripleTen Sprint 12

Modelado predictivo para seleccionar la región óptima de perforación de 200 nuevos pozos petroleros maximizando el rendimiento financiero y acotando la probabilidad de pérdidas.

  • Entrenamiento de modelos de Regresión Lineal para estimar reservas de crudo por región.
  • Aplicación de técnica de Bootstrapping (1,000 muestras) e intervalos de confianza del 95%.

Predicción de Abandono de Clientes (Beta Bank)

Noviembre 2026 | TripleTen Sprint 11

Sistema de clasificación supervisada para anticipar la fuga de clientes bancarios (Churn) corrigiendo el fuerte desequilibrio de clases del conjunto de datos original.

  • Optimización de métricas F1-Score y área bajo la curva (AUC-ROC) mediante sobremuestreo (Upsampling).
